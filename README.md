# ❤️ LoveCalc

LoveCalc é um projeto desenvolvido em Python que calcula uma porcentagem fictícia de compatibilidade amorosa entre duas pessoas a partir de seus nomes.

## Como funciona?

O programa recebe dois nomes, conta a frequência de cada letra e transforma essas contagens em uma sequência numérica.

Em seguida, realiza somas entre os dígitos das extremidades até obter um número de até dois dígitos, utilizado como porcentagem de compatibilidade.

## Tecnologias utilizadas

- Python 3
- Biblioteca padrão do Python

## Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Execute o programa:

```bash
python LoveCalc.py
```

Este projeto foi desenvolvido como exercício prático para aprimorar conhecimentos em lógica de programação, manipulação de listas, estruturas de repetição e funções em Python.
